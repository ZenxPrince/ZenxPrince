## About

I'm drawn to problems that live between disciplines — the kind that require you to understand software and hardware simultaneously, connect financial logic to systems architecture, or apply machine learning where it has no obvious right to work yet.

My focus spans **AI & intelligent systems, software engineering, embedded computation, electronics, robotics, cybersecurity, cloud infrastructure, distributed systems, and financial technology** — not as a credential list, but as an actual map of what I build, explore and think about. I care about how these fields intersect: using software to control physical systems, using embedded computation where cloud architectures would be overkill, and understanding finance well enough to build technology that actually interacts with it correctly.

I learn by breaking things down to first principles, building working prototypes and figuring out what actually fails. More interested in systems that do real things than systems that look impressive in a demo.
